## Team workflow

- Track work with GitHub Issues.
- Create a branch from main for each task.
- Use prefixes such as feature/, fix/, docs/, and chore/.
- Open a pull request; do not push completed work directly to main.
- Ask at least one teammate to review before merging.
- Keep pull requests small and link them to the relevant issue.
